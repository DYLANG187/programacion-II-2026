# Figuras Geométricas

Dylan Garcia 

9941-25-21652

## Descripción

Aplicación de consola desarrollada en Java para calcular el área de diferentes figuras geométricas utilizando programación orientada a objetos.

## Figuras implementadas

* Círculo
* Rectángulo
* Triángulo

## Instrucciones para ejecutar

1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar la clase `Main.java`.
3. El programa mostrará en la consola el nombre y el área calculada de cada figura.
