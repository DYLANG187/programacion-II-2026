# Sistema de Envíos

## Descripción

Aplicación de consola desarrollada en Java para registrar envíos nacionales e internacionales y calcular su costo final según las características de cada envío.

## Objetivo

Desarrollar una aplicación que permita aplicar conceptos fundamentales de Programación Orientada a Objetos, como encapsulamiento, constructores, herencia, sobrecarga, sobrescritura y polimorfismo.

## Temas aplicados

* Clases y objetos
* Atributos y métodos
* Encapsulamiento
* Constructores
* Herencia
* Sobrecarga de métodos
* Sobrescritura de métodos
* Polimorfismo
* Validación de datos

## Estructura del proyecto

```text
src/
├── Envio.java
├── EnvioNacional.java
├── EnvioInternacional.java
└── Main.java
```

## Instrucciones para ejecutar

1. Abrir el proyecto en IntelliJ IDEA.
2. Ubicar la clase `Main.java`.
3. Ejecutar el método `main`.
4. Seleccionar una opción del menú.
5. Ingresar los datos solicitados.
6. El programa calculará y mostrará el costo final del envío.

## Resultado esperado

El programa permite registrar envíos nacionales e internacionales, validar los datos ingresados y mostrar el costo base, los cargos adicionales y el costo final de cada operación.
