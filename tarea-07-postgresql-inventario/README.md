# Tarea 07 - PostgreSQL Inventario

## Nombre de la actividad
Diseño y manipulación de una base de datos de inventario en PostgreSQL.

## Descripción del problema
Se necesita una base de datos para controlar el inventario básico de una tienda. La aplicación debe permitir registrar productos, controlar su precio y stock, identificar si están activos y realizar consultas y operaciones básicas sobre los productos.

## Requisitos
- Crear una base de datos llamada `control_inventario`.
- Crear la tabla `producto`.
- Utilizar tipos de datos y restricciones en PostgreSQL.
- Registrar productos de prueba.
- Realizar consultas con filtros y ordenamiento.
- Realizar operaciones de actualización y eliminación.
- Comprobar restricciones mediante errores intencionales.
- Documentar las evidencias de ejecución.

## Base de datos
`control_inventario`

## Orden de ejecución
1. `01_creacion.sql`
2. `02_datos_prueba.sql`
3. `03_operaciones.sql`
