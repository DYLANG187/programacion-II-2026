## Caso seleccionado:

**Caso A – Registro de mascotas**

## Descripción:

El programa permite registrar tres mascotas utilizando una colección `ArrayList`. Mantiene las mascotas en el orden en que fueron registradas, permite recorrer la lista, mostrar la cantidad de mascotas, eliminar una mascota y mostrar nuevamente la lista actualizada.

También se controla la entrada numérica para evitar errores cuando el usuario ingresa letras en lugar de un número.

## ¿Por qué se utilizó ArrayList?

Se seleccionó `ArrayList` porque permite almacenar elementos manteniendo el orden de registro y facilita el recorrido, la adición y la eliminación de elementos.

## Funcionalidades:

* Registrar tres mascotas.
* Mostrar la cantidad de mascotas registradas.
* Recorrer y mostrar las mascotas.
* Eliminar una mascota.
* Mostrar nuevamente la lista después de eliminar.
* Controlar entradas numéricas inválidas mediante `NumberFormatException`.
