Semana 2 - Variables y Operadores

Nombre de la actividad:

Calculadora de Edad

Descripción:

Este programa de consola en Java solicita información básica del estudiante y calcula su edad aproximada utilizando el año de nacimiento y el año actual.

El programa también convierte la edad aproximada a meses y determina si la persona es mayor de edad.

La edad obtenida es aproximada porque el cálculo utiliza únicamente el año de nacimiento y el año actual, sin considerar el día y mes de nacimiento.

Datos solicitados:

El programa solicita los siguientes datos:

Nombre completo. Carné. Año de nacimiento. Año actual.

Cálculos realizados:

El programa realiza los siguientes cálculos:

Edad aproximada: resta el año de nacimiento al año actual.
Edad aproximada en meses: multiplica la edad por 12.
Mayoría de edad: compara la edad con 18 y almacena el resultado en una variable de tipo boolean.
Instrucciones para ejecutar el proyecto
Abrir el proyecto semana-02-variables-operadores en IntelliJ IDEA.
Abrir la clase CalculadoraEdad.
Ejecutar el método main.
Ingresar los datos solicitados en la consola.
